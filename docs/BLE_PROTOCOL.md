# 蓝牙协议（逆向整理）

适用于「追魅 / 昕达控制器」配套控制器。以下内容由抓包与静态分析整理，
不同固件版本可能有差异，**写操作请自行在授权设备上验证**。

## GATT

| 项目 | UUID |
| --- | --- |
| Service | `0000FFF0-0000-1000-8000-00805F9B34FB` |
| Write | `0000FFF2` |
| Notify | `0000FFF1` |
| CCCD | `00002902-0000-1000-8000-00805f9b34fb` |

连接后：发现服务 → 订阅 `FFF1` 通知 → 请求 MTU（默认请求 511，实际以设备协商结果为准）。
写入时按 `mtu - 3` 分片（最小 20 字节；原实现另有 130 字节分片路径）。

## 帧格式

- 实时帧头：`EC 9F`（大端）
- 多字节数值：16 位**小端**
- 校验：参数块末字节为前面字节的逐字节 XOR（fcs）
- 通知帧同样带校验，不匹配直接丢弃

## 连接流程（只读）

1. `openBluetoothAdapter` → 开始扫描
2. 过滤名称/广播数据，找到控制器
3. `createBLEConnection` → `getServices`
4. `notifyBLECharacteristicValueChange(FFF1)`
5. `setMtu(511)`
6. 读取参数/实时数据；写入仅在用户明确操作时进行

## 实时数据

App 展示的字段：转速（RPM）、母线电压、母线电流、相线电流、控制器状态位、
控制器温度、故障信息、档位（1/2/3/P/倒车/巡航/国标/防盗/刹车）、软件版本、
控制器工作电压。

## OTA

OTA 走同一 GATT 通道，升级前请确认固件型号与电量，避免升级中断。
